# CAT Practice Lab

A free practice app for the CAT exam that works offline in the browser. Open it at
https://develpr007.github.io/cat-practice-lab/ (on a phone: browser menu → "Install app" / "Add to Home screen").

This repository contains only the app's code. It contains no exam or institute material and no user data:
everyone adds their own PDFs, which are read and kept on their own device (and, if they sign in with Google,
in their own Google Drive). Privacy: see the app's Privacy page.
